สรุปเนื้อหา Cloud Network and Computing

วิชา 010123218 ฉบับเตรียมสอบปิดตำรา เน้นเรื่องที่ต้องเข้าใจและสูตรที่ใช้คำนวณ ตัดชื่อสินค้า ตัวเลขราคาและสเปก และคำสั่งที่ต้องท่องจำออกแล้ว แต่เก็บสูตรคำนวณไว้ครบ ศัพท์เทคนิคอธิบายไว้ตรงที่เจอครั้งแรก

แต่ละช่วงเปิดด้วยกล่อง "ช่วงนี้ต้องเข้าใจอะไร" และปิดด้วยย่อหน้า "ทวนก่อนสอบ" ถ้าเวลาเหลือน้อย ให้อ่านสองส่วนนี้ของทุกช่วงก่อน

เนื้อหาแยกเป็นไฟล์ละหนึ่งช่วง เรียงตามลำดับที่สอนในวิชา ช่วงหลังอ้างถึงเรื่องในช่วงก่อนอยู่บ้าง ถ้าเพิ่งเริ่มอ่าน แนะนำให้อ่านจากช่วงที่ 1 ไปตามลำดับ

  1. ช่วงที่ 1 พื้นฐาน Network, Cloud และ Virtualization
    Week 1–2: การเดินทางของข้อมูล, OSI กับ TCP/IP, NAT, นิยาม Cloud, IaaS/PaaS/SaaS, Region กับ AZ, virtualization, hypervisor, container และ storage
  2. ช่วงที่ 2 Cloud Networking, สถาปัตยกรรม และแล็บ
    Week 3 และแล็บ: VPC, CIDR, route table, Internet Gateway กับ NAT Gateway, SDN, NFV, สถาปัตยกรรมแบบ tier, Azure เทียบ AWS และแล็บ GetStart, WebApp, Build VPC
  3. ช่วงที่ 3 Cloud Security
    Week 4: shared responsibility, Security Group กับ NACL, IAM, VPN กับ Direct Connect, defense in depth และหลักการออกแบบ 8 ข้อ
  4. ช่วงที่ 4 AI Services, สถาปัตยกรรม และโครงสร้างพื้นฐานของ AI
    AI Service_Infra: LLM และ token, reasoning, multimodal, การเรียก API และราคา, function calling, MCP, agent, embedding, RAG, GPU, training กับ inference, quantization และการเลือกระหว่าง self-host กับ API
